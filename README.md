## About

**BUDDY NOVA** is a hands-on AI research and development project focused on understanding, designing, and building intelligent systems from the ground up.

This repository documents my journey from Python and mathematical foundations to neural networks, Transformers, language models, and practical AI systems.

The goal is not simply to use AI tools, but to understand how they work by implementing components, running experiments, testing ideas, and documenting what I learn.

## Vision

To explore how an intelligent, adaptable, and useful AI assistant can be built through deep learning, experimentation, and responsible engineering.

## Mission

- Learn the fundamentals instead of skipping straight to frameworks.
- Implement important components through hands-on coding.
- Experiment, test, debug, and document every major step.
- Build toward an AI assistant with useful, understandable capabilities.
- Share the learning process and make the project accessible to others.

## Guiding Principles

**Understand → Design → Build → Test → Explain**

Every major learning phase should result in both a stronger understanding of the concepts and a working project component.

- **Understand:** Study the underlying ideas.
- **Design:** Plan the implementation.
- **Build:** Write and organize the code.
- **Test:** Check behavior and investigate failures.
- **Explain:** Record what works, what doesn't, and why.

## Getting Started

### Prerequisites

- Python 3.11 or newer
- Git
- Visual Studio Code (recommended)

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/buddy-nova.git
cd buddy-nova
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Create a Virtual Environment

**Windows PowerShell:**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, use the environment's Python executable directly:

```powershell
.\.venv\Scripts\python.exe --version
```

### 3. Run the Project

Once the initial application entry point has been implemented:

```powershell
python .\src\buddy_nova\main.py
```

### 4. Run Tests

Once tests have been added:

```powershell
python -m unittest discover -s tests -v
```
